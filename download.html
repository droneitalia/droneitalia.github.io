Come installare il file APK

Scarica il file sul telefono Android e aprilo dalla cartella Download. Segui le indicazioni di Android; se richiesto, autorizza l’installazione per l’app con cui hai aperto il file. Per aggiornare un’installazione esistente, apri il nuovo APK e scegli Aggiorna.
